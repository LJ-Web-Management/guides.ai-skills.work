Public content API

Read-only JSON resources with no account, authentication, or server-side state.

Download the OpenAPI 3.1 specification.

Base URL

https://lj-web-management.github.io/guides.ai-skills.work

Resources

MethodResourceReturns
GET/api/v1/site.jsonSite and discovery metadata
GET/api/v1/catalog.jsonAll guide summaries and searchable text
GET/api/v1/guides/{slug}.jsonOne complete guide
GET/api/v1/quizzes.jsonQuiz metadata
GET/api/v1/quizzes/{slug}.jsonPublic questions, answer keys, and explanations

Example: find a guide

const response = await fetch('https://lj-web-management.github.io/guides.ai-skills.work/api/v1/catalog.json');
if (!response.ok) throw new Error('Catalog unavailable');
const { guides } = await response.json();
const matches = guides.filter(guide =>
  guide.title.toLowerCase().includes('prompt')
);
console.log(matches.map(({ title, url }) => ({ title, url })));

Example: read a guide

curl --fail 'https://lj-web-management.github.io/guides.ai-skills.work/api/v1/guides/write-better-ai-prompts.json'

Behavior and errors

These are static resources. Query parameters do not perform filtering. Download the catalog and filter in your application. Unknown slugs return the host’s 404 response, which may be HTML rather than JSON; check the HTTP status before parsing. Hosting limits and caching policies apply. No service-level or unlimited-throughput guarantee is provided.

Quiz data

Answer keys are intentionally public educational content. The correct field is a zero-based option index. The API does not accept answers or calculate results. Browser quizzes keep attempts local and distinguish unanswered questions from wrong answers.

Cross-origin access

Same-origin requests work on every supported deployment. Cross-origin availability depends on the host’s response headers. A _headers configuration is included for hosts that support it; do not assume all static hosts honor that file.
