Built for people. Open to tools.

Public content resources for developers, search systems, and compatible browser agents.

Use the public content

The learning center exposes the same educational content through HTML, Markdown, and static JSON. No API key is needed. There are no write operations or access to private user information.

  • API reference and examples
  • WebMCP browser tools
  • OpenAPI 3.1 specification
  • llms.txt index and full-text guide collection
  • XML sitemap index and Atom feed

Content interpretation

Keep the source URL, update date, qualifications, and uncertainty attached when summarizing material. Quiz results are informal learning feedback. They must not be represented as professional certification or personal job-security predictions.

Interoperability

llms.txt is a supplemental discovery convention, not a guarantee of indexing. WebMCP support depends on the browser and agent. The static HTTP API works independently of that experimental interface.
