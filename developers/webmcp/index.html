WebMCP browser tools

Experimental, read-only tools for agents in compatible browsers.

What is registered

When a supported API is present, the page registers three tools. Current proposal support is detected through document.modelContext, with a navigator.modelContext compatibility fallback. The normal site continues to work when neither is available.

  • search_guides: accepts a search query and optional category; returns public guide metadata. Search results update visibly when the search page is open.
  • get_guide: accepts an exact catalog slug and returns the public lesson, examples, FAQs, and source links.
  • list_quizzes: lists quiz titles, descriptions, question counts, and URLs.

Boundaries

These tools do not access quiz selections, score or submit attempts, send messages, modify accounts, or navigate the browser. Tool calls produce a visible status message or update the current search results. Inputs are validated before content is read.

Discovery and compatibility

webmcp.json documents the site’s tools. It is an informational file, not a standardized WebMCP manifest or a remotely callable MCP server. Tool registration happens inside the page. Browser and agent support is experimental and may change.

HTTP alternative

For server-side integrations, use the static content API and OpenAPI specification. They do not depend on browser-agent support.

Specification

See the WebMCP proposal for current browser API details. Availability of these tools does not imply that an AI service indexes or endorses the site.
