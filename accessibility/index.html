THE AI SKILLS FIELD GUIDE

Built to be approachable

Keyboard access, readable content, reduced motion, and accessible question cards.

Read and navigate your way

The site uses semantic headings, descriptive links, a skip link, visible focus indicators, and layouts designed to reflow on small screens. Main content is available as HTML without requiring JavaScript.

Quiz controls

Quiz answers use labeled native radio controls. You can navigate with a keyboard, change earlier answers, skip questions, and review explanations. Incomplete submission uses a dialog with clear choices. JavaScript is required for interactive scoring.

Motion preferences

Animations are decorative and do not convey essential information. The site respects your system’s reduced-motion setting and removes unnecessary movement when that preference is enabled.

Text and alternatives

Important information is presented as text. Decorative illustrations are hidden from assistive technology. Guide articles also have Markdown alternatives, available from the end of each article.

Report a barrier

Use the main site’s official support route and include the affected URL, the action you were trying to complete, and relevant browser or assistive technology details. This statement describes intended features, not a claim of independent accessibility certification.
