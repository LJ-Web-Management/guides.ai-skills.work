# Better prompts. More useful answers.

Learn a reusable prompt structure with clear goals, relevant context, constraints, and examples.

## Give the task a clear destination

Say what you want the assistant to produce and who will use it. Include the information it needs and the format you expect. Replace broad instructions such as make this better with an observable goal, such as shorten this email to 120 words while keeping the deadline and action items. Clear instructions make the result easier to assess.

- Goal: the job you want completed.
- Context: the audience, inputs, and relevant situation.

## Set boundaries and show an example

Specify constraints such as length, tone, source material, and information the assistant must not invent. If the output needs a particular structure, provide a short example. Ask the assistant to flag missing information rather than fill gaps with guesses. A role description can help set perspective, but it does not create actual professional expertise.

- Format: the structure of the output.
- Boundaries: facts to preserve, exclusions, and uncertainty to surface.

## Improve the result with specific feedback

Read the first answer before requesting more. Identify one concrete problem and ask for a targeted change. For complicated tasks, request an outline or sample before the full output. Keep useful prompts as starting points, but adapt them when the audience, evidence, or task changes.

- Ask for alternatives when the tradeoff is unclear.
- Verify the final result even if the prompt was detailed.

## Try it yourself

Rewrite one vague prompt with a goal, audience, input, format, and two constraints. Compare the two results against the same checklist.

## Common questions

### Does a longer prompt always work better?

No. Relevant information and clear requirements matter more than length. Extra instructions can distract or conflict.

### Can a prompt prevent all mistakes?

No. A good prompt improves direction, but output still needs verification appropriate to the task.
